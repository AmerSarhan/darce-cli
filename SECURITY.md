# Security

Darce runs commands on your machine, so security reports matter a lot here.

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/AmerSarhan/darce-cli/security/advisories/new) rather than a public issue. Include what an attacker controls (for example a repository you clone, a web page Darce reads, or a model's output), what they can make Darce do, and steps to reproduce.

You'll get a reply within a few days. Fixes ship as a new npm version, with credit in the changelog if you'd like it.
